# 測試 PR 交付流程

當你請 AI 幫忙提交修改並建立 PR，它可能把你留給其他工作的修改一起提交，或把舊版本通過的測試當成新版本已經通過。這次加入幾道模擬題，檢查 AI 寫出的做法是否會犯這些錯誤。

## 如何解讀結果

有提供指引時通過 11 項評分條件，沒有提供時通過 9 項，其中前者與後者在它通過之前如果那次的結果並非這次的結果而它又沿用之前已確認的那個，雖然這兩個在其他條件都相同時原本應該一致，仍須以它最後讀回的那個為準，但如果它沒有完成這件事，即使另一個已經完成，也不能把它視為這個已完成，除非確認前面所說的條件仍然成立。

差異是繁體中文與標題格式。安全條件兩組都通過，不能據此說實際交付更安全。
